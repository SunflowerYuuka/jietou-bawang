# 验收清单

> 这份清单按“能照着做”写的。每条都标了**预期结果**，和“如果不对说明什么”。

## 0. 装之前

```
mods/
├── astrum-0.1.0-FINAL.jar
└── geckolib-neoforge-1.21.1-4.9.3.jar     ← 必须单独装，没装会加载失败
```

进入游戏后，`选项 → 控制` 里应该能看到三个键位：

| 键 | 默认 | 作用 |
|---|---|---|
| Astrum 设置 | `K` | 打开配置界面 |
| Astrum 释放 | `V` | 点按放大招 / 长按出提示条 |
| Astrum 轮盘 | `B` | 长按切换预设 |

## 1. 角色卡与入册

| 步骤 | 预期 |
|---|---|
| 合成台放 纸 + 金粒 + 青金石 | 得到「角色卡」 |
| 手持右键 | 姬塔入册，聊天栏有提示 |
| 再右键同一张 | **不消耗**，提示「已在册」 |
| 给可可萝/佩可莉姆/凯露也各做一张 | 四张卡各自入册对应角色 |

**如果不对**：检查 `config/astrum-server.toml` 里的日志级别，或看 `logs/latest.log` 有没有 `astrum:` 开头的 WARN。

## 2. 角色册界面

| 检查 | 预期 |
|---|---|
| 右键角色册 | 面板打开，**背景是角色立绘** |
| 面板四角 | **没有黑色方块**（之前的 bug） |
| 左侧角色格 | 每格显示**头像**（不是文字） |
| 点头像 | 背景立绘切换成该角色 |
| 编队槽 | 显示头像，不是空圆 |
| 技能列表 | 每行有图标，**攻击提升用的是金框火焰图** |

**如果四角还有黑块**：说明 `CornerCutout` 没生效，把截图发我。

## 3. 好感度与头像变化

| 好感度 | 预期头像 |
|---|---|
| 1~2 | 1★ 头像 |
| 3~7 | 3★ 头像 |
| 8+ | **6★ 头像**（姬塔/可可萝/佩可莉姆/凯露都有） |

同时**背景立绘**：3 阶时从 3★ 立绘换成 6★ 立绘。

## 4. 技能轮转（这次的核心改动）

按 `V` 或左键攻击，观察聊天栏/状态栏：

| 攻击次数 | 预期触发的技能 |
|---|---|
| 第 1 刀 | 姬塔·广域斩击（额外伤害） |
| 第 2 刀 | 姬塔·剑意迸发（充能提升） |
| 第 3 刀 | **回到广域斩击** |

**四个角色同时在队**时：每刀**同时触发所有人的当前技能**，但各自轮转独立。

**如果不对**：说明 `SkillGroups` 的 `skill` 分组没生效。

## 6. 状态栏布局

| 检查 | 预期 |
|---|---|
| 右上角原版药水栏 | **只显示临时效果**（加速、破甲等） |
| 五个角色的状态 | 移到**自绘的一排**（不是原版药水栏） |
| 图标 | 显示**施加者的技能图标** |

**如果不搬**：药水栏会塞满 5 个角色 + 若干临时效果，溢出。

## 7. 已知的近似与限制

这些是**设计上接受的**，不是 bug：

| 项 | 说明 |
|---|---|
| 物防/魔防拆分 | MC 没有 `is_magic` 标签，只能靠我们的 `astrum:magic` 标记。**其他 mod 的魔法伤害会被当物理** |
| 恐慌 | 服务端只能做到"不能移动/攻击/交互"，**作弊客户端仍能发包** |
| 防禦上限 60% | 原版抗性 5 级 = 100% 无敌，我们刻意不做到 |
| 加速 | 只提升移速+攻速，不像原作还影响技能冷却 |
